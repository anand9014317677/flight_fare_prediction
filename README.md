\# Flight Fare Prediction System



This project predicts flight ticket prices using Machine Learning.



\## Project Overview

The application estimates the flight fare based on airline, source, destination, journey date, departure time, arrival time, duration, and total stops.



\## Model Used

\- Random Forest Regressor

\- Scikit-learn



\## Features

\- End-to-end machine learning workflow

\- Data preprocessing and feature engineering

\- Streamlit web application

\- Real-time fare prediction



\## Input Features

\- Airline

\- Source

\- Destination

\- Total Stops

\- Journey Day \& Month

\- Departure Time

\- Arrival Time

\- Duration



\## Output

Estimated Flight Fare Price.
